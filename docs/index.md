# Java 技术笔记

欢迎来到我的 Java 技术笔记。

这里记录了一名 Java 开发者在日常工作中积累的技术知识与最佳实践，涵盖从环境搭建到架构设计的各个层面。

## 内容分类

- **开发环境** - JDK、IDE、Maven、Gradle、Docker 等环境配置
- **写作环境** - Markdown、图床、发布流程等
- **Java 核心** - 集合、并发、JVM、新特性等
- **Spring 生态** - Spring Boot、Spring Cloud、Spring Security 等
- **中间件** - Redis、RabbitMQ、Elasticsearch、Nginx 等
- **数据库** - MySQL、PostgreSQL、MyBatis、Flyway 等
- **DevOps** - Git、CI/CD、Kubernetes、监控等
